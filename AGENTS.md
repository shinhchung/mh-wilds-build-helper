# MH Wilds Build Helper

Expo + React Native + TypeScript mobile app for Monster Hunter Wilds build recommendations.

## Tech Stack
- React Native (Expo)
- TypeScript
- Vite
- React

## Project Structure
- `App.tsx` - Main app entry point
- `src/components` - Reusable UI components
- `src/data` - Game data models
- `src/logic` - Build recommendation logic
- `src/theme` - Shared color tokens
- `src/types` - TypeScript type definitions

## Commands
- `npm install` - Install dependencies
- `npm run start` - Start development server with Expo
- `npm run build` - Build for production
